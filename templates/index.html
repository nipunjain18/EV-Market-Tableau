QUICK ANSWERS

Frequently asked questions.

Everything you need to know about the EV360 analytics platform and underlying dataset.

What dataset powers the EV360 dashboard? +

The platform is powered by a verified 100,000-record dataset spanning 37 technical, economic, and regional attributes, covering global EV models from 2018 to 2026.

How was the data cleaned and processed? +

Data was processed using Python (pandas, NumPy) and SQLite. Missing values were imputed using domain-specific medians, and 5 analytical features were engineered: Range per $1,000, Price Segment, Range Class, Fast-Charge Rating, and Estimated Revenue.

How are the Tableau visualizations embedded? +

Visualizations are embedded using Tableau Embedding API v3 components with responsive containers, preserving full interactivity, filter propagation, and high-performance rendering.

Can I download the project deliverables and report? +

Yes! You can download the comprehensive 13-page PDF project report, view the SQL queries, and access the open-source repository directly through the navigation links.
